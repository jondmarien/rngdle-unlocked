# Ranked seed runbook

**Goal:** multi-human Ranked presence before/at spike. No bots. No multi-account fraud.

## Steps
1. List 5–10 real people (friends/Discord) who will create accounts.
2. Each: sign up → verify email → set `@username`.
3. Each: switch to **Ranked**, roll a handful (respect hour cap).
4. Confirm names appear on Leaderboard → Ranked.
5. Optional: one person holds a visible “today” score so the home crown card is not empty.

## Success
- [ ] ≥5 distinct Ranked usernames visible (adjust target if needed)
- [ ] At least one non-chrono name on today/week if possible

## Forbidden
- Fake accounts farmed by one person for theater
- Inflating claims in public posts (“thousands of players”) if untrue
