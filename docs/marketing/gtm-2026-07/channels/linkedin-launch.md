# LinkedIn launch post

I shipped **RNGdle Unlocked** — a browser game that rejects the daily-lock model.

You roll 0–1,000,000 anytime, collect badges, score entropy points, and optionally enter **Ranked** competition backed by server CSPRNG (so crowns are not “trust me bro” client rolls). There is also Arcade Digits as a separate run loop.

Design choices I cared about:
1. Local-first Free play by default
2. Honest split between Practice and Ranked boards
3. Shareable rolls without forcing an account for basic play

Live: https://rngdle-unlocked.chron0.tech  
Open source: https://github.com/jondmarien/rngdle-unlocked  

Not affiliated with rngdle.com.

If you build consumer web products: the hard part was not the reel animation. It was competitive integrity + still shipping something fun in a week-scale loop.
