# Quick Start

## Play only (no backend)

```bash
corepack enable
corepack prepare pnpm@10.34.4 --activate
pnpm install
pnpm dev
```

Open the URL Vite prints (usually `http://localhost:5173`). Rolls and badges work immediately with no env vars.
