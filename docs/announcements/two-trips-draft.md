# System announcement draft — Two Trips scoring (forward-only)

Ready to paste into Admin → System messages / broadcast. Do not auto-post.

**Title:** Two Trips scoring update

**Body:**

We added a new poker-hand badge for rolls with two distinct digits each appearing three times (for example 233223). Those rolls now score as **Two Trips** instead of a single Three of a Kind.

This applies to **new rolls only**. Past results, leaderboard ranks, badge history, and sealed rolls are unchanged.
